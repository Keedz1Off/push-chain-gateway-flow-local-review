# Glossary

## Codebase

```text
The full project code.
```

## Source Chain

```text
The chain where the user starts the transaction.
```

## Destination Chain

```text
The chain where the transaction is finalized or executed.
```

## TSS

```text
Off-chain signer / relayer system that reads events and finalizes transactions.
```

## Vault

```text
Finalize-side contract that receives TSS calls and sends funds to CEA.
```

## CEA

```text
Chain Executor Account. A smart account used to execute the final payload.
```

## Payload

```text
Encoded action / calldata that should be executed.
```

## Revert Recipient

```text
Refund address used if the universal transaction fails.
```

## Event

```text
Blockchain log used by off-chain systems.
```

## Invariant

```text
A rule that must always stay true.
```

## Suspicious Zone

```text
A security-sensitive place that needs deeper checking.
```
